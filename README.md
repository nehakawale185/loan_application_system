# Loan Application System

A simple web-based Loan Application System developed using
HTML, CSS, and JavaScript.

## Modules

1. Login and Registration
2. Customer Dashboard
3. Loan Application
4. Admin Dashboard

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage
- Git and GitHub

## Requirements

- Google Chrome or another modern web browser
- Visual Studio Code (optional)
- Git (for version control)

## How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open index.html in your browser.
4. Alternatively, use the Live Server extension in VS Code.

## Disclaimer

This is an academic demonstration project.
It stores demo information in browser Local Storage.
It does not use a secure backend or database and must
not be used for real financial transactions.
